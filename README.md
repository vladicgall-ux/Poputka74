# Поехали 74 — попутчики Челябинск ⇄ Кунашак

Telegram-бот + Mini App для поиска попутчиков между Челябинском и Кунашаком.
Водители публикуют поездки, пассажиры бронируют места. Все данные хранятся
в SQLite, бронирование места не требует созвона — контакты передаются
через уведомления бота после подтверждения брони.

## Защита от фейков

- Все действия в Mini App авторизуются по `initData`, подписанному Telegram
  (HMAC-SHA256 секретом бота) — подделать чужой `telegram_id` нельзя.
- Публиковать поездки и бронировать места может только пользователь с
  **подтверждённым номером телефона**. Номер подтверждается через кнопку
  «Поделиться номером» в чате с ботом (`request_contact`) — Telegram
  гарантирует, что присланный контакт принадлежит отправителю.
- Анкета водителя (машина, номер) обязательна для публикации поездок.
- На одну поездку пассажир не может забронировать место дважды.

## Стек

- **Бот**: Node.js + TypeScript + [Telegraf](https://telegraf.js.org/) (long polling)
- **API**: Express, авторизация через заголовок `X-Telegram-Init-Data`
- **БД**: SQLite (`better-sqlite3`), схема — `src/db/schema.sql`
- **Mini App**: чистый HTML/CSS/JS (`public/`), Telegram WebApp JS SDK, SVG-баннер

## Структура проекта

```
src/
  config.ts              загрузка .env
  db/                     подключение к SQLite + schema.sql
  services/               работа с пользователями, поездками, бронированиями
  server/                 Express: маршруты /api/users, /api/rides, /api/bookings
  bot/                    Telegraf-бот (регистрация, подтверждение телефона)
  utils/telegramAuth.ts   проверка подписи initData
public/
  index.html, styles.css, app.js   Mini App (SPA без сборки)
  assets/banner.svg                баннер приложения
```

## Запуск

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Скопируйте `.env.example` в `.env` и заполните:
   - `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
   - `WEBAPP_URL` — публичный HTTPS-адрес, где будет доступен `public/`
     (для локальной разработки можно временно пробросить порт через ngrok/Cloudflare Tunnel)
3. Соберите и запустите:
   ```bash
   npm run build
   npm start
   ```
   Либо для разработки с автоперезапуском:
   ```bash
   npm run dev
   ```

Сервер поднимает Express (отдаёт `/api/*` и статику Mini App) и запускает
Telegram-бота на long polling на одном процессе.

## Настройка в @BotFather

1. `/newbot` — создать бота, получить `BOT_TOKEN`.
2. `/setmenubutton` (или Bot Settings → Menu Button) — указать тот же
   `WEBAPP_URL`, чтобы кнопка меню тоже открывала Mini App.
3. Задеплойте `WEBAPP_URL` на любой HTTPS-хостинг (Render, Railway,
   VPS + nginx, Fly.io и т.д.) — Telegram Mini App требует HTTPS.

## Основные сценарии

- **/start** в боте → регистрация, кнопка подтверждения телефона, кнопка
  открытия Mini App.
- **Пассажир**: открывает Mini App → «Поиск» → выбирает направление →
  «Забронировать место» (после подтверждения телефона).
- **Водитель**: «Предложить» → подтверждает телефон в боте → заполняет
  анкету автомобиля → публикует поездку (дата, цена, места, комментарий).
- **Мои поездки**: водитель видит и может отменить свои поездки; пассажир —
  свои бронирования.
- При бронировании бот присылает водителю уведомление с контактом
  пассажира, а пассажиру — подтверждение с контактом водителя.

## API (кратко)

Все запросы требуют заголовок `X-Telegram-Init-Data`.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/users/me` | текущий пользователь + анкета водителя |
| POST | `/api/users/me/driver-profile` | создать/обновить анкету водителя |
| GET | `/api/rides?from=&to=` | поиск активных поездок |
| GET | `/api/rides/mine` | поездки текущего водителя |
| POST | `/api/rides` | опубликовать поездку |
| POST | `/api/rides/:id/cancel` | отменить поездку |
| GET | `/api/bookings/mine` | бронирования текущего пассажира |
| POST | `/api/bookings` | забронировать место |
| POST | `/api/bookings/:id/cancel` | отменить бронирование |
